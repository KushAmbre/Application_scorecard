# Application Scorecard

This project develops a **Home Loan Application Scorecard** to accelerate and streamline loan approval decisions. By leveraging data preprocessing, feature engineering, and model development, the scorecard helps financial institutions make quick and data-driven lending decisions.

## Project Highlights

- **Data Preprocessing & EDA:**  
  Conducted thorough data cleaning and exploratory data analysis to understand the dataset’s structure and key features.

- **Variable Engineering:**  
  Created new variables and performed variable selection using Information Value (IV), feature importance, and variable clustering.

- **Model Development:**  
  - **Logistic Regression Model:** Used coarse classing and binning, followed by a looped approach to calculate bad rates for each decile and identify significant variables.  
  - **Decision Tree Model:** Developed decision stumps and fine-tuned variable selection and hyperparameters.

- **Results:**  
  The final scorecard model improves the speed and reliability of loan decision-making, leading to better risk management.

## Technologies Used

- Python  
- Pandas, NumPy  
- Seaborn, Matplotlib  
- Logistic Regression, Decision Tree
